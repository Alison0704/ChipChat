# ChipChat - An RAG AI assistant for Hardware Chip Design

This is a small project aiming to use OpenAI's API to its model, along with a RAG system, for easing documentation fetching requirements for ASIC processing.

## Content of the Project

The Project includes:
- A RAG chatbot interface.
- A documentation directory containing a folder for project specifications.
- `[Future implementation]` Verilog/SystemVerilog coding and compilation window.
- `[Future implementation]` Built in waveform viewer.
